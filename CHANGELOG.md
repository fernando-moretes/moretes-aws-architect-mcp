# Changelog

## 0.3.0 — 2026-10-25

Trust and contracts release. Same 48 tools.

- `iam_policy_review` gains `provider`: Azure custom role definitions (wildcard actions, notActions complements, dataActions, role-assignment escalation, key listing, broad scopes) and Google Cloud IAM bindings (basic roles, public members, service account impersonation, consumer accounts, missing conditions and etag).
- `outputSchema` published for every calculation and review tool, inferred from the real outputs and tolerant by design; the SDK client validates `structuredContent` against it.
- Contract tests: every `docs/examples` output must reproduce exactly; `docs/tools.lock.json` pins a sha256 of name, description and input schema per tool.
- CI: contracts up to date, coverage summary; CodeQL (security-and-quality), Dependabot, CycloneDX SBOM artifact on each release; MCP Registry publication via OIDC.
- README: one-click install for Cursor and VS Code, CI/CodeQL/Registry badges.

## 0.2.0 — 2026-10-24

Cloud-agnostic workbench release. 48 public tools (was 24), 20 prompts, 18 resources, a pipeline CLI and a fairer public quota.

Added

- Architect personas: `architect_panel` tool, `architect_<role>` prompts and `moretes://personas/<id>` resources for solution, enterprise, business, data, infrastructure, software, AI, security, governance and FinOps architects.
- Code and dependencies: `code_review_architecture`, `dependency_manifest_review`.
- Design: `c4_model`, `sequence_diagram`, `service_equivalents` (43 capabilities across AWS, Azure, GCP, OCI and open source), `data_classification` (LGPD, GDPR, PCI DSS, HIPAA pointers), `openapi_review`, `event_contract`. `architecture_pattern` gains a `provider` mapping.
- Reliability, operations and FinOps: `latency_budget`, `queue_sizing` (Erlang C), `dr_strategy`, `retry_policy`, `storage_growth`, `finops_unit_economics`, `postmortem`, `runbook`.
- AI agents and MCP safety: `agent_eval_plan`, `prompt_injection_checklist`, `rag_pipeline_plan`, `mcp_server_review`, `mcp_config_review`.
- IaC: `terraform_plan_review` (plan JSON, any provider), `kubernetes_manifest_review`.
- Skills as resources (`moretes://skills/*`): architecture review, ADR writing, agent production readiness, IaC change review, cost scenario.
- CLI `moretes-architect` (`list`, `describe`, `call` with `--input`, `--format json|markdown|sarif`, `--fail-on`, exit codes 0/1/2).
- Per-caller daily quota (300, pseudonymous `sha256(day + IP)`) on top of the global one (now 3,000); API throttle raised to 5 rps / burst 20.
- `/.well-known/mcp/server-card.json`, `/.well-known/glama.json` and `/tools.json` on the public host.
- `docs/examples/*.json` with real outputs, regenerated by `scripts/examples.mjs`; `PRIVACY.md`.

Changed

- Tool listing is grouped and deterministic (stable prompt caches). Version lives in `src/version.ts`.
- `package.json` declares `bin`, `files`, `mcpName` and a `prepare` build; still not published to npm.

Known limits: heuristic reviews, shared public quota, local-only account access, no remote OAuth, no npm or registry publication yet.

## 0.1.0 — 2026-10-24

Initial public architecture workbench: 24 public tools, optional local AWS identity/inventory/cost tools and two allowlisted federation operations; official AWS Knowledge connection; catalog snapshot and pinned package configurations; HTTP/stdio transports; infrastructure, docs and tests.
