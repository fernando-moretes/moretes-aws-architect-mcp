# Roadmap

## v0.1 scope

- [x] Public stateless MCP + local stdio
- [x] Architecture and evidence-based review tools
- [x] Five live AWS Knowledge adapters
- [x] Official catalog, pinned configuration generation
- [x] Local authenticated account tools and opt-in provider bridge
- [x] AWS CloudFormation deployment definition, quota and budget alerts
- [x] Protocol, calculation and negative tests

Deployment/CI results are recorded separately in docs/deployment.md; this list describes implemented scope.

## Next, based on real users

- Five external developers complete the workshop; record friction and outcomes with permission.
- Dedicated contract tests for the most requested official providers (pricing, ECS, serverless, Transform).
- Add user-supplied trace evidence to architecture reviews, with local redaction.
- Consumer package publication after install/upgrade tests and publisher authentication.
- Authenticated per-user quotas and remote account access only after an OAuth/delegation threat model and isolation tests.
- Optional signed release provenance and registry submission.

No promise of every provider working, certification, exact monthly charges, or community award results.
